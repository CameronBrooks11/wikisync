# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository
(<https://github.com/CameronBrooks11/wikisync/security/advisories/new>).

Include what you found, how to reproduce it, and what an attacker could do with
it. wikisync handles bot-password credentials and writes files named after
wiki titles, so reports about credential handling or about paths escaping the
working tree are especially welcome.

Reports are acknowledged and fixed on a best-effort basis.

## Supported versions

Only the latest release gets fixes.
